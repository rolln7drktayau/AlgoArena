AlgoArena - Quick Start Commands
===============================

Complete step-by-step tutorial (FR):
------------------------------------
See: GUIDE_COMPLET_FR.md

Windows PowerShell (manual)
---------------------------
cd E:\AlgoArena
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt

# Terminal 1 (backend)
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 (frontend)
cd frontend
npm install
npm run dev

Windows PowerShell (one command)
--------------------------------
powershell -ExecutionPolicy Bypass -File .\scripts\start_windows.ps1

Windows PowerShell (web-first + toasts)
---------------------------------------
powershell -ExecutionPolicy Bypass -File .\scripts\start_windows.ps1 -WebFirst

Build Windows EXE launcher
--------------------------
powershell -ExecutionPolicy Bypass -File .\scripts\build_launcher_exe.ps1

Run EXE launcher
----------------
.\dist\AlgoArenaLauncher.exe
.\dist\AlgoArenaLauncher.exe -WebFirst

WSL / Linux (manual)
--------------------
cd /mnt/e/AlgoArena
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt

# Terminal 1 (backend)
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2 (frontend)
cd /mnt/e/AlgoArena/frontend
npm install
npm run dev

WSL / Linux (one command)
-------------------------
chmod +x scripts/start_wsl.sh
./scripts/start_wsl.sh
