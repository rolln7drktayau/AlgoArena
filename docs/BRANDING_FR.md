# Logo AlgoArena

Source : logo fourni par l’utilisateur, lettre A cyan et barre bleue sur fond sombre.
Version utilisée : `assets/branding/logo-approved.png`. La génération intégrée imagegen
a amélioré la netteté ; aucune API externe configurée manuellement n’a été utilisée.
Les déclinaisons PNG et ICO sont converties avec `scripts/install_brand_asset.js`.
Les anciennes variantes dans ce dossier restent des archives et ne sont pas affichées.

Prompt final de nettoyage :

> Clean up this exact logo to a perfectly crisp professional app icon. Keep same A
> geometry and blue cyan colors. Solid opaque dark navy #111e2b square background.
> Remove ALL edge noise, jagged cyan outlines, artifacts. Flat clean straight edges,
> no textures no glow. Enlarge symbol to occupy 75% canvas height centered.
> Preserve detached blue lower bar. 1024x1024.
